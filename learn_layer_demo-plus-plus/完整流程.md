POST /api/login:
详细流程：
→ func Login(c *gin.Context)【handler层】
1. 从http请求体拿到json账号密码 → 绑定解析到 dto.LoginDTO
2. dto结构体：{Username string, Password string}
3. handler调用 service.Login(req.Username,req.Password)
→ service层调用 repository.GetUserByUsername(username)
→ SQL: select * from user where username = ?
→ 查询返回 model.User（包含数据库存的加密后的密码哈希值）
→ service拿到用户数据后，**比对密码**
将前端传过来的明文密码 和 数据库里存的加密哈希密码校验
→ 密码校验成功，返回 user.ID 向上给到 handler
4. handler拿到 user.ID，调用 GenerateToken(userID) 生成JWT令牌
5. 将token封装成json，返回给前端
直观流程：
   前端明文账号密码 → Handler → Service
   ↓
   Repo: 根据用户名查询用户 → 返回用户+加密密码哈希
   ↓
   Service：后端内存对比【明文密码 ↔ 哈希密码】
   ↓
   校验成功 → 返回userId → Handler生成JWT Token → 返回前端

核心疑问：为什么先查出整条用户记录，之后才比对密码？
数据库里面存的密码，从来不是明文密码！存储的是密码哈希。
用户前端输入明文密码：`123456`
但注册的时候后端加密，存入数据库的值：`$2a$10$EixZaY/sb0RW2lyYyGIcvuq6e6WQdGyspq8ixsIQM0B6jZPUxMQfy`
哈希是单向加密！不能反向解密得到原始明文密码
那数据库 SQL 比对为什么行不通？
你前端传过来的是明文`123456`，数据库里面存的是一串哈希字符串。
你拿明文 `123456` 直接放进 SQL 条件和哈希字符串做相等判断，结果永远不可能匹配。



## 完整时序（访问 GET /api/profile）
详细流程：
1. 前端发送请求，Header 携带 `Authorization: Bearer eyJhbGciOi...`
2. 请求命中路由 `authGroup.GET("/profile", handler.GetProfile)`
3. **优先执行中间件 JWTAuthMiddleware**
   - 从 `c *gin.Context` 获取 Authorization 请求头 `authHeader`
   - 分割字符串，切掉 `Bearer `前缀，得到纯净令牌字符串 `tokenStr`
   - 调用 `ParseToken(tokenStr)` 解析 JWT。
   >
   > 这里的回调函数就是 `jwt.ParseWithClaims` 的第二个回调，用来传入你自定义的 `MyClaims` 结构体；校验后端密钥是否匹配、检查签名。
   - 解析成功得到 token 对象；使用类型断言 `token.Claims.(*MyClaims)`，取出载荷内部存储的 `UserId`、过期时间等信息
   - 将 `userId` 存入 gin 上下文：`c.Set("userId", userId)`。
   - `c.Next()` 放行，请求往下走到业务 handler。
4. 来到 `handler.GetProfile(c *gin.Context)`
   - handler 第一步：**从 gin.Context 中取出刚才中间件放进去的 userId**
   - - handler 只做接收上下文、参数校验、调用 service、封装返回 VO 的工作，**不直接碰数据库**
- 调用 service 层：`userService.GetProfile(userId.(uint))`
5. repository 层 `repository.GetUserByIdPtr(userId)`
   - 只负责执行 SQL 查询：`select * from user where id = ?`
   - 返回数据库原始实体 `*model.User`
   - repository**不处理任何业务逻辑，只做数据库读写**
6. 结果原路逐层向上返回。前端拿到 VO 后渲染个人中心页面。 

直观流程：
前端请求带Bearer Token
↓
路由命中/api/profile → 先走JWTAuthMiddleware鉴权
↓
解析Token拿到userId → c.Set("userId",userId)放行
↓
handler.GetProfile：c.Get取出userId
↓
service.GetProfile(userId)
↓
repository.GetUserByIdPtr(userId) → 查询数据库得到model.User
↓
service：model.User → vo.UserInfoVO（过滤密码敏感字段）
↓
handler接收VO，返回JSON → 前端个人中心页面渲染
